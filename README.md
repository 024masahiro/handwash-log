# 手洗い・手指消毒ログ

職員が自分の手洗い・手指消毒の回数を記録し、管理者が利用者別の回数を確認するアプリです。手洗いと手指消毒は区別せず、同じボタンで1回として記録します。

**このブランチは無料プランで運用する移行版です。サービスの設定・データ移行・動作確認後に公開を切り替えます。** 切り替え前の公開版は従来の保存先を使用します。

画面は **GitHub Pages**、ログインとメール送信は **Firebase Authentication（Spark）**、記録と管理者APIは **Cloudflare Workers / D1（Free）** を使います。移行後はChatGPTのアカウントやサイトへの接続が不要です。

- 氏名・メールアドレス・パスワードの別々の欄で登録できます。
- 本人の記録だけを追加・取消できます。日付は日本時間で集計します。
- ログインした利用者は今日のランキングを閲覧できます。手洗い・手指消毒の合計で上位10位を表示し、同じ回数は同順位として全員を含めます。ランキングには氏名・回数・順位だけを表示し、本人の順位も確認できます。
- 管理者は利用者別ダッシュボードを閲覧し、一般利用者とその記録を削除できます。
- 一般登録で管理者権限は付与されません。所有者は専用の非公開操作で設定します。
- Firebaseから再設定リンクをメールで自動送信します。
- 本人は現在のパスワードを確認して退会できます。管理者アカウントは削除から保護します。
- サーバーで署名・プロジェクト・失効・停止状態と現在の権限を確認します。
- 保存と集計に索引を使い、本人の全履歴を毎分読み直す処理をなくしています。

[無料プランの設定手順](docs/free-setup.md)に初回設定、移行、公開の手順をまとめています。約20人の通常利用を想定しています。無料枠には上限があり、課金プランへ変更せず運用します。

## 開発・検証

Node.js 22以上を使用します。

```sh
npm ci
npm run test:free
```

ローカルのFirebase認証エミュレーターとD1で、権限・失効・再設定コード・削除と再試行・旧パスワードとSQL移行を検証します。本番の利用者やメール送信は使用しません。

```sh
# firebase-web.example.jsonをfirebase-web.jsonにコピーして実際の公開設定を入力
npm run build:free
```

GitHub PagesのSourceはGitHub Actionsにします。Firebaseの公開設定は `firebase-web.public.json` に登録済みです。`HANDWASH_API_ORIGIN` に公開したWorkerのURLを設定します。設定不足・エミュレーター設定を検出すると公開ビルドを停止します。

Firebaseの設定は `FIREBASE_WEB_CONFIG` の環境変数、ローカルの `firebase-web.json`、リポジトリの `firebase-web.public.json` の順に読み込みます。公開設定はブラウザに配信する4項目のみです。サービスアカウントの秘密鍵は含めません。

利用者情報、記録、旧パスワードハッシュ、Googleの秘密鍵、CloudflareのAPIトークンは公開リポジトリへ入れません。`private-migration/` と `worker/wrangler.json` はGitの対象外です。従来のSites用ソースは切り替え前の確認・書き込み停止に使いますが、新しい公開ビルドには含みません。
